# DungeonTome findings

This is where players of **DungeonTome**, the dungeon journal addon for WoW Forever, send what their tome has learned.

While you play, the tome quietly notes the drops it sees, how often things drop, and the bosses it meets. Sending those notes here helps everyone: they go into the next update, so the tome's drop chances and loot tables get better for all players.

## How to share

1. In game, open the tome, go to the **Settings** ribbon and click **Share what the tome has learned**, or type `/tome share`.
2. Click **Copy code**, then press **Ctrl+C**. On a Mac, press **Cmd+C**.
3. **[Open a new findings report](../../issues/new?template=share-findings.yml)**, paste the code into the box and submit.

You'll need a free GitHub account to submit.

Send a new code whenever you like. Your newer code replaces your older one, so nothing is counted twice.

## What's in a code

Only what the tome has noted on your travels:

- the drops it saw, and from which creatures
- how many corpses were looted, and how often each item was on them
- the bosses it met

**Nothing about you:** no character names, realms, runs, gold, wishlist or settings. Each code carries a random tag, so the tome can tell your newer code from your older one, but the tag doesn't identify you.

Reports here are public, like everything on GitHub, and your GitHub username shows on any report you submit.

## How reports are used

Codes are read by the tome's keeper and folded into the next update. Reports from different players are checked against each other: a new drop only goes in once more than one player has seen it, and unusually large counts are capped, so one odd report can't skew the tome.

Thank you for helping fill in the tome.
